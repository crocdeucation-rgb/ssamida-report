3. 대입지도 무료 진단

원칙

  • 금지합격예측 · 합격 확률 · "대교협"
  • 사용"대학이 발표한 실제 50%컷·70%컷 기준"
  • 타겟: 고1·2 + 예비 중3(고입) — 고3은 돌리지 않음

데이터 (고1 · 내신 3.2 · 반도체 계열 예시)

등급3.2(지금)2.72.21.7
지원 가능5곳16곳26곳36곳
  • 5등급제 3.2 = 9등급제 5.06 (실측 환산)
  • 같은 3.2 · 교과 5곳 vs 학종 10곳

잡은 이슈

  • 헤드 "0.5등급"인데 숫자 5→36(1.5등급 차) → 5→16곳으로 수정
  • 5종이 같은 헤드·숫자·색 → 퀴즈 / 환산 / 전형비교 / 리포트실물로 재구성
  • 1a·3a·3b 허전함 → 문 아이콘 16개 그리드, 성적표 동그라미, 리포트 블러

4. 수행평가 (핵심 킥)

수행평가 비율, 실제 조회

지역내용
서울"학기 성적 40% 이상" — 예전(2021) 방침. 2026은 서·논술형 30% 확대 발표, 비율 수치는 미확인
경기2026학년도부터 수행평가 비율 30%로 조정
전국시·도교육청 대체로 40% 내외, 과목당 2~3회
대구5개 주요 교과 논술·구술형 수행평가 의무화

카피"40%" 단정 금지 → "학교에 따라 30~40%", 막대 30/30/40은 "예시" 표기

실제 과제 재료

  • 수학(교육청 자료집 예시): 세금 함수 만들기 · 나만의 수열 그래프 · 부등식 사업 전략 · 스프레드시트 실근 찾기 · 수학사 미적분 구술
  • 과학(고1 평가계획): 4컷 만화(미완성 시 내용 0점) · 주기율표+발표+동료평가 · 치즈 만들기 · 색 변하는 용액 · 토양 중화 보고서
  • 영어(학생 후기·평가계획 예시): 주제 에세이 · 독후감 · 말하기 발표 · 작품 분석 보고서
  • 평가 방식: 프로젝트 · 조사 · 실험·실습 · 전시 · 토의·토론 · 논술·구술

중등 수행 = 고입 성적

  • 중학교 성적 = 수행평가 + 지필평가 합산
  • 외고·국제고 1단계: 중2-1 ~ 중3-2 영어 4개 학기 성취도 (A 40 / B 36 / C 32), 동점 시 국어·사회
  • 서울 자사고는 1단계 추첨 → "자사고" 통째로 묶지 말 것 (하나고 등 일부만 교과성적)
